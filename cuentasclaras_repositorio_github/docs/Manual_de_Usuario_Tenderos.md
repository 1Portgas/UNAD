# Manual de Usuario - CuentasClaras para Tenderos de Barrio

## 1. Registro Rápido de Fiados (< 15 Segundos)
1. Presione el botón verde **`+ Nuevo Fiado`**.
2. Seleccione el cliente deudor. El sistema mostrará en pantalla su deuda actual y el cupo disponible.
3. Ingrese el monto en pesos (puede utilizar los botones rápidos de `+5.000`, `+10.000` o `+20.000`).
4. Si el monto supera el cupo máximo permitido, el sistema emitirá una alerta preventiva en rojo exigiendo autorización.
5. Presione **`Confirmar Fiado`**. El sistema procesa la transacción de inmediato y emite confirmación auditada.

## 2. Registro de Abonos
1. Presione **`- Registrar Abono`** o ubique al cliente en la tabla y pulse **`Abonar`**.
2. Si el cliente paga la totalidad, use el botón directo **`Pagar Totalidad`**.
3. Seleccione el medio de recepción (Efectivo, Nequi, Daviplata o Bancolombia a la Mano).
4. Confirme la operación para descontar automáticamente la deuda.

## 3. Alta de Cliente con Cumplimiento de Habeas Data (Ley 1581 de 2012)
* Todo nuevo deudor debe autorizar el uso de sus datos de contacto y registro de deuda marcando la casilla de consentimiento legal previo al guardado.
